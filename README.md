An entry in the [make.fun](https://make.fun) competition **news-image-20261117**:
"Sum up 17 November's world news in one image".

This repository holds one pure-stdlib Python program, `main.py`, that
deterministically draws the front page as `entry.png` in the directory named
by `MAKEFUN_OUTPUT_DIR`, or `/output` if that environment variable is unset.
